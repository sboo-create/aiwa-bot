# Быстрый цикл правок фронта AIWA

## Где находится канон

- Продуктовые компоненты и экраны: `src/aiwa/`.
- Локальный каталог компонентов с фикстурами: `src/storybook/`.
- Единственный вход в TMA-компоненты: `src/aiwa/lib/tma.js`.
- Локальная runtime-копия Deslop: `vendor/deslop-tma/`.
- Эталон для сравнения исходников: `~/deslop/mini-app/`.

Продукт не импортирует компоненты из `~/deslop` и не зависит от него при
сборке. Если эталон подходит не полностью, его поведение переносится в локальный
gateway/компонент и сразу добавляется в каталог. Цвета меняются в
`src/aiwa/styles/theme.css`, композиция — в `composition.css`, шрифт интерфейса —
через `--ui-font-interface`.

## Повседневный цикл

1. Запустить каталог с HMR:

   ```bash
   npm run front:dev
   ```

   Открыть `http://localhost:5173/storybook/`. Узкий viewport ближе всего к
   Telegram; широкий удобен для быстрого сравнения нескольких состояний.

2. Исправить исходник в `src/aiwa/` и проверить компонент/состояние в каталоге.

3. Отправить свежий фронт в тестового Telegram-бота одной командой:

   ```bash
   npm run front:deploy
   ```

   Команда проверяет реестр и UI-контракт, собирает Vite-бандл, автоматически
   повышает номер бандла и cache key, инкрементально синхронизирует только
   `webapp2/` и проверяет публичные HTML/JS. `systemctl restart` не выполняется.

4. Закрыть и снова открыть Mini App в Telegram. Если WebView удержал старый
   документ, полностью выгрузить Mini App; у JS/CSS уже будет новая ревизия.

Перед коммитом или завершением серии правок запустить полную проверку:

```bash
npm run verify
```

Она дополнительно собирает весь локальный каталог.

## Команды

| Команда | Назначение |
| --- | --- |
| `npm run front:dev` | Каталог компонентов с HMR |
| `npm run front:build` | Быстрые контракты, production build и публикация в `webapp2` |
| `npm run front:deploy` | `front:build` + rsync на Hetzner + публичная проверка |
| `npm run front:deploy -- --dry-run` | Показать rsync-дельту без записи на сервер |
| `npm run verify` | Полная локальная проверка перед сдачей |

Значения Hetzner по умолчанию уже соответствуют тестовому стенду. Для другого
стенда доступны `AIWA_FRONTEND_SSH_HOST`, `AIWA_FRONTEND_SSH_KEY`,
`AIWA_FRONTEND_REMOTE_ROOT` и `AIWA_FRONTEND_URL`.

## Правила изменений

- Новая продуктовая деталь сначала появляется в `src/aiwa/components`, затем в
  `src/aiwa/index.js`, `design-system/registry.json` и `src/storybook/pages.jsx`.
- `@deslop/tma` импортируется только через `src/aiwa/lib/tma.js`.
- Цветовые литералы допустимы только в `styles/theme.css`; компоненты используют
  `--aiwa-*` и Deslop-токены.
- Сгенерированный JS не редактируется. `webapp2/assets/deslop` обновляет
  `scripts/publish_webapp_bundle.py`.
- Если исправляется сам эталон Deslop, это отдельная правка в `~/deslop`; в AIWA
  переносится проверенная локальная сборка с обновлённым `ORIGIN.md`.
