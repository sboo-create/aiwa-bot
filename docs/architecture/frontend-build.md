# Фронт Mini App: исходники и сборка

Исходники React-приложения (deslop redesign) лежат в `frontend/`, собранный
артефакт — в `webapp2/assets/deslop/`. **Правки делаются только в исходниках**,
бандл руками не трогаем.

## Сборка

```bash
scripts/build-frontend          # bun install + vite build + установка артефакта
```

Имена чанков стабильные и версионированные: `deslop-main-aiwa-vNNN.js`.
Версия задаётся `AIWA_UI_VERSION` (по умолчанию — константа в
`frontend/vite.config.js`); поднимай её при заметных изменениях UI, чтобы
Telegram не отдавал старый файл из кэша. После сборки подними `?v=rNN`
у `main.js`/`main.css` в `webapp2/index.html`.

Легаси-файлы каталога (`fonts/`, `aiwa-v163.css`) не собираются, но
раздаются и нужны `index.html` — скрипт их сохраняет.

## История: как исходники вернулись

Редизайн выкатили 27.07 (коммиты Сони, тест-группа → все за 5,5 часов), но в
репозиторий попадал только минифицированный бандл. Дальше правки v163→v177
вносились **прямо в минифицированный код** — 65 фрагментов. Исходники жили
на одном ноутбуке, и любая пересборка стёрла бы эти правки.

31.07 исходники восстановлены из рабочей копии, и все 65 фрагментов
портированы в JSX. Паритет подтверждён сравнением пользовательских строк
собранного бандла с продовым: **не потеряно ни одной**.

Что было портировано (по кластерам):

| Кластер | Суть |
|---|---|
| Пилатес | отдельный тип тренировки, свои упражнения, распознавание в тексте |
| Выписка | флаг `delivered`, попап с возвратом в чат, антидубль-клик, оба места вызова |
| Мужской режим | тексты выписки/данных/чата, доступная главная, `cycle_len` только для цикла |
| Утренняя сводка | тумблер включения, `/api/daily-summary`, отражение в списке |
| Картинки еды | серверные `image_url`, точное совпадение вместо нечёткого подбора, заглушки блюда/напитка |
| Ассеты | лёгкий опрос `/api/food-assets/revision` вместо тяжёлого поллинга секции |
| Дневник за день | просмотр прошлого дня, запрет добавления в чужой день |
| МСК-дата | `aiwaTodayIso()` вместо UTC-полуночи (сдвиг дня на телефонах) |
| Кэш экранов | TTL 1,5 с вместо вечного кэша |
| Талисман | статичный кадр вместо покадровой анимации на главном потоке |
| Аватар | общий `ProfileAvatar` с фото Telegram на всех экранах |

## Правила

- не редактировать `webapp2/assets/deslop/*.js` — правка живёт до первой сборки;
- изменения фронта проверять на staging до прода;
- при добавлении экранов держать мост со склейкой (`window.AiwaDeslop`,
  `call`/`read`) в актуальном состоянии — именно на этом шве возникали
  баги записи «не в тот день».
